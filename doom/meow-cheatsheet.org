* Symbol Keys

| Key | Command                 | Description                  |
|-----+-------------------------+------------------------------|
| {   | backward-paragraph      | Jump to previous paragraph   |
| }   | forward-paragraph       | Jump to next paragraph       |
| ^   | negative-argument       | Negate numeric prefix        |
| :   | execute-extended-command | M-x command prompt           |
| $   | save-buffer             | Save file                    |
| _   | avy-goto-char-timer     | Avy jump to any visible char |
| -   | switch-to-buffer        | Switch buffer                |
| #   | comment-line            | Toggle line comment          |
| =   | +lookup/references      | Find references              |
| *   | magit-status            | Open git interface           |
| /   | meow-next-word          | Move forward one word        |
| ?   | meow-next-symbol        | Move forward one symbol      |

* Motion Mode

| Key | Command       | Description            |
|-----+---------------+------------------------|
| a   | next-line     | Move cursor down       |
| e   | previous-line | Move cursor up         |
| ESC | ignore        | Do nothing             |

|-----+--------------------------+-------------------------------|

* Custom Functions (config.org)

| Function              | Description                                                                  |
|-----------------------+------------------------------------------------------------------------------|
| meow-word             | Toggle word/symbol selection: first call selects word, second expands to symbol |
| meow-kill-line        | Kill from cursor to end of line, respecting meow-use-clipboard               |
| meow-change-line      | Kill to end of line and enter insert mode (like vim's C)                     |
| meow-save-clipboard   | Copy selection to system clipboard regardless of global clipboard setting    |
| meow-yank-dwim        | Smart paste: replaces region if selected, handles line-wise yanks correctly  |
| meow-yank-pop-dwim    | Like meow-yank-dwim but cycles through kill ring                             |
| meow-smart-reverse    | Reverse selection if active, otherwise start negative argument               |
| meow-kmacro           | Toggle keyboard macro recording (start/stop)                                 |
| meow-eldoc            | Toggle eldoc documentation window visibility                                 |

* Notes

- Navigation cluster (=h a e i=) sits on the right-hand home row on Gallium
- =p= is unbound — good candidate for custom binding
- Things (prompted by =y=, =,=, =k=, =K=): round, square, curly, string, paragraph, line, buffer, etc.
